# Trolley 짧은 사용 가이드

이미 실행 중인 Trolley 서버에서 **사용자를 초대하고, 허용된 도구를 사용하는 방법**입니다. 사용자는 서버나 PostgreSQL을 설치할 필요가 없습니다. MCP를 지원하는 AI 클라이언트만 준비하세요.

> 아래 `https://trolley.example.com`은 실제 서버 주소로 바꿔 주세요. 다른 사람에게는 `localhost`가 아닌, 그 사람이 접속할 수 있는 HTTPS 주소를 안내해야 합니다.

## 1. 관리자: 공유할 도구 준비하기

**준비 조건:** 관리자 API 키로 MCP 클라이언트에 연결되어 있고, 서버에 데이터베이스와 초대 메일 발송용 SMTP가 설정되어 있어야 합니다.

먼저 AI에게 요청하세요.

> Trolley에서 내 권한과 사용 가능한 도구를 알려줘.
> 등록된 Operation과 그룹을 확인해줘.

Operation은 관리자가 SQL과 입력값을 승인해 등록한 도구입니다. 이미 공유할 도구와 그룹이 있다면 재사용하세요. 없다면 다음처럼 요청합니다.

> finance 그룹을 만들고, 월별 매출 조회 도구를 준비해줘.
> 실제 DB 스키마를 확인해서 SQL과 입력값을 먼저 제안해줘.
> 내가 검토하고 승인하면 restricted 권한으로 등록하고 finance 그룹에 사용 권한을 부여해줘.

- 도구 생성: `create_operation`
- 그룹 생성: `create_group`
- 그룹에 도구 권한 부여: `grant_group_operation`

**주의:** 기본 접근 정책인 `public`은 일반 로그인 사용자에게도 도구를 공개합니다. 특정 그룹만 사용하게 하려면 `restricted`로 설정하세요. 그룹 권한은 도구 실행 권한이며, 결과의 행을 사용자별로 자동 필터링하지는 않습니다.

## 2. 관리자: 사용자 초대하기

AI에게 다음처럼 요청하세요. 이메일과 이름, 그룹은 실제 값으로 바꿉니다.

> analyst@example.com 사용자를 이름 “김분석”으로 Trolley에 초대하고,
> finance 그룹에 추가해줘. invite_user로 초대 메일을 보내줘.

이때 호출되는 도구와 입력 예시는 다음과 같습니다.

```text
invite_user
```

```json
{
  "email": "analyst@example.com",
  "name": "김분석",
  "group_names": ["finance"]
}
```

사용자는 **API 키와 연결 안내 URL이 담긴 이메일**을 받습니다. 그룹은 미리 만들어져 있어야 하며, 서버 재시작은 필요 없습니다.

> 재초대하면 새 API 키가 발급되며 기존 키는 유지됩니다. SMTP가 없다면 서버 운영자에게 발송 설정을 요청하세요. 수동 키 발급·전달 방법은 [상세 가이드](guide.md#invite-a-member)를 참고하세요.

## 3. 사용자: AI 클라이언트 연결하기

1. 초대 이메일을 열어 연결 안내 URL을 확인합니다.
2. AI에게 **API 키가 아닌 안내 URL만** 전달합니다.

   > 이 페이지를 읽고 Trolley 연결을 도와줘:
   > https://trolley.example.com/onboarding.md
   > API 키는 내가 클라이언트 설정에 직접 입력할게.

3. 클라이언트의 MCP 서버 설정에 연결 정보를 추가합니다. 클라이언트에 따라 수동 설정이 필요할 수 있습니다.

   | 항목 | 값 |
   |---|---|
   | 서버 URL | `https://trolley.example.com/mcp/` |
   | 인증 방식 | Bearer API 키 |
   | 인증 헤더를 직접 설정하는 경우 | `Authorization: Bearer <초대받은 API 키>` |

4. API 키는 클라이언트의 비밀값·인증 설정에 **직접 입력**합니다.
5. 설정을 저장하고 MCP 연결을 다시 연결하거나 클라이언트를 재시작합니다.

**API 키는 비밀번호처럼 취급하세요. AI 대화, 공유 문서, Git 저장소에 붙여넣지 마세요.**

## 4. 사용자: 도구 사용하기

연결 후 먼저 물어보세요.

> Trolley에서 내가 할 수 있는 일을 알려줘. 사용 가능한 도구도 보여줘.

AI는 `get_my_capabilities`와 `list_operations`로 권한과 도구를 확인합니다. 이후 등록된 도구에 맞춰 자연어로 요청하면 됩니다.

> 2026년 8월 매출을 조회해줘.

원하는 도구가 없다면:

> 이 작업을 할 수 있는 도구가 있는지 확인해줘.
> 없다면 관리자에게 보낼 요청 내용을 작성하고, 내 확인을 받은 뒤 제출해줘.

요청에는 비밀번호, API 키 등 민감 정보를 넣지 마세요.

## 연결이 안 될 때

| 증상 | 확인할 것 |
|---|---|
| 서버에 접속되지 않음 | 실제 서버 주소, 네트워크/VPN 접근 여부 확인 |
| `401` 오류 | API 키 누락·오입력 또는 키/계정 비활성 여부 확인 |
| 도구가 안 보이거나 권한 오류 | 관리자에게 그룹 가입과 도구 권한 확인 요청 |
| 새 도구가 목록에 없음 | `list_operations`를 다시 요청하고, 필요하면 MCP 재연결 |
| 초대 메일이 안 옴 | 스팸함 확인 후 관리자에게 SMTP 및 발송 결과 확인 요청 |
